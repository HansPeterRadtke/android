# Bundled German language data and licensing

`app/src/main/assets/de_lexicon.json` contains an adapted and transformed rank-ordered German lexical list. This generated combined dataset is distributed under **Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)** because it combines CC BY-SA data. Attribution does not imply endorsement.

1. **wordfreq version 3.1.1** by Robyn Speer and contributors, https://github.com/rspeer/wordfreq. The German rank ordering was derived from its `top_n_list('de', 24000)` database, which is licensed under CC BY-SA 4.0 and contains frequency information derived from several language corpora. See the original project's data credits and license text before distribution. The library code itself has a separate license. Word frequency entries have been filtered and German word surface forms adjusted.
2. **german-wordlist** by Markus Enzenberger (enz) and contributors, https://github.com/enz/german-wordlist. The lexicon is CC0 1.0 Universal (`COPYING` in its repository). Only word-surface casing was used as auxiliary data.
3. **german-nouns** by the project's maintainers and German Wiktionary contributors, https://github.com/gambolputty/german-nouns. Distributed under CC BY-SA 4.0 (see upstream `LICENSE`). Lemma/inflected noun casing was used to restore common noun capitalization.
4. A small, explicitly written list of common German place names was added to the generator to improve local capitalization.

Reproduce the lexicon using `scripts/make_lexicon.py` and the above two source files plus `wordfreq==3.1.1`. The script does not require a model inference service, phone permissions or proprietary Google lexicon. The generated input archives are not committed. The app's end-user learned word statistics belong to the user and are *not* part of this CC BY-SA reference lexicon.

## GIF provider access and rights (v0.6.0)

The user may enter their own GIPHY developer API key in the Android Settings activity. Keys are private local app configuration and are not included in GitHub, builds, bug reports, analytics, or normal typed content. The user's actual GIPHY search query is sent only after explicitly searching in the GIF panel. The integration is marked `Powered By GIPHY` and accepts G, PG, PG-13, and R ratings. GIPHY's rating scheme and hosted media remain subject to GIPHY's developer and content terms, which are independent of the app's CC BY-SA word data: https://developers.giphy.com/docs/ and https://developers.giphy.com/docs/optional-settings/rating/ . A test-key rate limit is not a license to mirror or resell GIPHY media; this implementation uses platform-supplied media URLs. Binary downloads are limited to the user-initiated image share operation and bounded temporary Android cache.

Tenor's third-party API was terminated in June 2026 by Google, but its official `tenor.com/search/` website remains accessible in users' browsers. The keyboard's `Tenor-Web` entry opens the browser rather than accessing a discontinued API or extracting website data. The user must share or save content through the website/browser's own interface. No Tenor content is bundled or ingested into a local library.

KLIPY is a viable official competitor but its current documentation requests prior provider approval for custom integrations, caching or mixing sources. This version does not bypass that requirement or reuse third-party keys. The keyless Google Image Search approach used by independent software was not copied: automated search scraping is contrary to Google's stated machine-traffic restrictions. Wikimedia Commons and Openverse remain separate, clearly labelled limited educational GIF sources; each result has its own license. No unrestricted anonymous reaction-GIF API was verified, and the app does not pretend otherwise.

## v0.7 baseline German/English next-word model (Tatoeba contributors)

To give relevant predictions *before the next word is started*, the app bundles only frequency-weighted **aggregate bigram, trigram and sentence-start counts** derived from Tatoeba's public English and German sentence exports (`eng_sentences.tsv.bz2`, `deu_sentences.tsv.bz2`), dated October 31, 2026. These data are copyrighted by Tatoeba's sentence authors and reused under their default **Creative Commons Attribution 2.0 France** license (CC BY 2.0 FR), which permits redistribution and adaptation with attribution. Project and authors: [Tatoeba](https://tatoeba.org/) and its [contributors' public attribution records](https://tatoeba.org/), official corpus source https://downloads.tatoeba.org/exports/per_language/ and license https://creativecommons.org/licenses/by/2.0/fr/ . The full, original sentences and their author-level provenance remain on Tatoeba, including the sentence IDs in Tatoeba exports. No sentences or conversation logs are shipped with the APK. The derived aggregate ngram data are also offered under CC BY 2.0 FR with this attribution; the user's private adaptive statistics remain separate and unchanged. See [Tatoeba re-use guidance](https://en.wiki.tatoeba.org/articles/show/using-the-tatoeba-corpus) and its [FAQ](https://en.wiki.tatoeba.org/articles/show/faq).

Regenerate the two bundled binary GZIP data files with `scripts/make_next_word_data.py`, using the official per-language source files. The files are named `de_next_words.ngram` and `en_next_words.ngram` (opaque extension preserves raw GZIP bytes because Android's asset packager may automatically decompress `.gz` files and rename them). The generator uses deterministic selection of sentence subsets, removes some overrepresented fictional names and non-Latin or long phrases, counts two/three-token continuations, selects common contexts and caps each to a small number of candidates. Retained counts originate from about three hundred and thirty thousand German and three hundred and seventy-five thousand English sentences after filtering. The compact offline model has around three hundred thousand context-conditioned candidate entries, compressed into approximately one and a half megabytes combined. It is **not** a full grammar-correct or transformer-quality language model. Real-world accuracy has not been statistically benchmarked against Gboard. Local learned words and selections are given much larger scoring weights than these population-level defaults.

Loading the corpus is confined to a dedicated background worker; it must not block `InputMethodService` startup and does not cause any network requests during typing. Settings offer explicit deletion of the user's private learning data; the generic bundled model is read-only.

## English Chime model (v0.8.0)

The binary `app/src/main/assets/chime_en.ltc` is an unchanged copy of the published `cifg_int8.bin` checkpoint from [Chime-SMS-2M](https://huggingface.co/lukeslp/chime-sms-2m), copyright **Luke Steuber, 2026**, licensed [Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The model's SHA-256 matches the publisher's `config.json`. The separately authored on-device Java runtime is an Apache-2.0-reference-derived implementation of the published CIFG algorithm; the repository includes `third_party/chime/LICENSE.md`, `NOTICE.txt` and `config.json` as source and license attribution. The published reference tokenizer/inference code is Apache 2.0. The keyboard Settings activity prominently names the author, license and model link. Its runtime uses no remote inference or model hosting and transmits no ordinary typing text. Chime's fixed English vocabulary does not include German morphology. The original model may have inherited biases and error patterns from its text corpus; user-selected words override its guesses. The provider's `NOTICE.txt` lists additional underlying training-data credits. No non-redistributable external corpus files were bundled.


## On-device German neural model (v0.9.0)

`app/src/main/assets/german_next_word.nwp` is an unmodified copy of `de.nwp.bin` from https://huggingface.co/youcoded/next-word-german , built/released by Destin Moss via youcoded.ai in October 2026. The quantized checkpoint contains a vocabulary and model weights, with 4.3 million learned parameters; its license is **Open Data Commons Attribution 1.0 AND Creative Commons Attribution 2.0 France**, and its checksum at source was `bb881b20d227c7b1ed7c9a04d67171b08c25494a10b2f11138eb7914194dac84`. Its underlying corpora include FineWeb/FineWeb-2 (Hugging Face, ODC-By 1.0; Common Crawl terms also apply) and Tatoeba contributors (CC BY 2.0 FR). The original release's notices are preserved under `third_party/german-neural/NOTICE.md`, `ODC-By-1.0.txt`, `TATOEBA-CC-BY-2.0-FR.txt`, and `README.md`. Author credits and licenses remain in the app's README and Settings. No source web corpus is bundled, and no private typed text is uploaded or used to retrain the weights. The model's finite vocabulary may omit private names, technical terms or newly coined German words; in those cases the personalized statistics and generic word lists can still suggest them. The words displayed are not guaranteed to be correct in context.

### German contextual casing corpus (v0.9.0)

`app/src/main/assets/de_word_case.gcase` is a GZIP-compressed set of **aggregate token and preceding-word case counts**, generated using `scripts/make_german_casing.py` from the official Tatoeba German sentence export. Attribution: Tatoeba's contributors, [CC BY 2.0 France](https://creativecommons.org/licenses/by/2.0/fr/), https://tatoeba.org/ and https://downloads.tatoeba.org/exports/per_language/deu/ . It contains no sentences, identifiers, names of sentence authors, private user strings, or individual text passages. The original corpus remains available at the cited official sources. The asset is about 837 KB and supplies capitalization statistics for roughly 20,000 recognized word forms and their frequent predecessors. It is a heuristic, not an authoritative German grammar resource.


## ReactionGIFs.com in version 0.20

The keyless picker reads the public RSS feed at https://www.reactiongifs.com/feed/ or the site's RSS search results. It displays source credit on each result and links the original post when sharing to a compatible editor. Media is fetched on demand. The APK contains no GIFs from this provider.
